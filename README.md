# Atlantis The Royal Residences – Unit Catalog

Static page (no build step). Open `index.html` locally, or host with GitHub Pages.

## Publish on GitHub Pages
1. Create a new repository on github.com (e.g. `atlantis-catalog`).
2. Upload `index.html`, `README.md` and the whole `assets` folder (drag and drop, keep the folder structure).
3. Settings > Pages > Source: "Deploy from a branch", Branch: `main`, Folder: `/ (root)`.
4. Your link will be `https://<your-username>.github.io/<repo-name>/` (ready in 1-2 minutes).

Note: Pages sites on standard GitHub plans are public to anyone who has the link. The page asks search engines not to index it, but it is not password protected.
